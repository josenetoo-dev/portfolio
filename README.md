# Developer Hub — José Neto

Portfólio pessoal em HTML, CSS e JavaScript, sem dependências.

## Executar localmente
Abra `index.html` no navegador ou use um servidor estático.

## Publicar no GitHub Pages
1. Crie o repositório público `josenetoo-dev.github.io`.
2. Envie os arquivos e a pasta `assets/` para a raiz.
3. Em Settings → Pages, selecione a branch `main` e a pasta `/ (root)`.
